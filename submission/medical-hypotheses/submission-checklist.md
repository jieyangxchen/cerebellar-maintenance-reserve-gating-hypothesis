# *Medical Hypotheses* submission checklist

**Candidate:** version 0.3.0, prepared 31 August 2026

**Status:** public candidate; not yet submitted

## Scientific fit and boundaries

- [x] The title and abstract present one falsifiable hypothesis rather than an established mechanism.
- [x] The observable environmental model is separated from the unobserved $X$/gating extension.
- [x] The manuscript states that current human data do not demonstrate $X$, a gate, outward loss, or a hump-shaped exposure curve.
- [x] Alternative explanations, temporal requirements, perturbational evidence, and layer-specific rejection rules are explicit.
- [x] SCA3 is the primary test bed; SCA6 is a transport test rather than pooled confirmation.
- [x] Full cohort/trial detail remains in the repository; the article contains only the design decisions needed for falsifiability.
- [x] The article reports no participant-level data or new human or animal experiments and makes no treatment recommendation.

## Manuscript package

- [x] Abstract is 250 words or fewer.
- [x] Six keywords are supplied.
- [x] All 26 numbered references are cited, and every numbered citation has a reference.
- [x] Fig. 1, Fig. 2, and Fig. 3 are cited immediately before their placement and have complete legends.
- [x] Funding, competing interests, author contribution, acknowledgements, ethics, and data/code statements are present.
- [x] The Elsevier-style generative-AI declaration appears immediately before the references.
- [x] The public GitHub preprint is disclosed in the title page and cover letter.
- [x] The manuscript is not under consideration by another journal.

## Author actions in the portal

- [ ] Read and personally approve all three final Word files.
- [ ] Enter the author name, ORCID, affiliation, email, and any required postal address exactly.
- [ ] Select the standard/subscription publication route; verify that the displayed mandatory author charge is zero before final confirmation.
- [ ] Disclose the public preprint/repository wherever the portal asks about prior dissemination.
- [ ] Copy the AI declaration exactly if the portal provides a separate AI-use field.
- [ ] Supply only reviewers the author can identify without conflicts; do not invent reviewer details.
- [ ] Preview the publisher-generated submission PDF and verify all equations, symbols, figures, captions, and references.
- [ ] Save the final submission confirmation, manuscript ID, and downloaded portal files before updating GitHub status.
