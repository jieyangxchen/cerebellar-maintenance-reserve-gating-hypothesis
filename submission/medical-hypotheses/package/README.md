# *Medical Hypotheses* submission package

**Candidate:** manuscript version 0.3.1, prepared 1 September 2026

**Evidence cut-off:** 19 August 2026

**Status:** public submission candidate; not yet submitted or tagged as a journal-submission release

This directory contains seven uploadable Word files for a fresh, double-anonymized submission to *Medical Hypotheses*:

1. `01_Anonymized_Manuscript.docx` — reviewer manuscript without author identifiers or identifying Word metadata;
2. `02_Title_Page.docx` — author, affiliation, correspondence, acknowledgements, and disclosure metadata; upload as the non-reviewer title page;
3. `03_Cover_Letter.docx` — journal-specific cover letter;
4. `04_Highlights.docx` — four editable Highlights, each no longer than 85 characters;
5. `05_CRediT_Author_Statement.docx` — named contributor-role statement; exclude from reviewer files if the portal allows;
6. `06_Declaration_of_Interest.docx` — declaration and repository-licensing clarification;
7. `07_Ethics_Statement.docx` — ethics and consent applicability statement.

All seven Word files have creator, last-modified-by, custom-property, and revision-session metadata scrubbed. The anonymized manuscript also omits the author name, affiliation, email, ORCID, acknowledgements, named CRediT statement, and direct repository URL. The public preprint remains discoverable by title, so file anonymization reduces direct disclosure but cannot guarantee that a reviewer will not infer authorship through an external search.

`SHA256SUMS.txt` records the exact generated bytes. Rebuild after any source change with:

```bash
.venv/bin/python submission/medical-hypotheses/build_submission_package.py
```

The complete cohort protocol, statistical analysis plan, and early-intervention concepts remain in the public repository and are not submitted as an additional Word supplement in this package. They are research-planning documents, not validated protocols or clinical recommendations.

The public GitHub manuscript is disclosed as a preprint. Elsevier's general sharing policy permits authors to share preprints; the author should still answer every journal-portal prior-dissemination question accurately.

To avoid an author publication charge, select the journal's standard/subscription publication route in the submission or post-acceptance workflow. Do not select paid gold open access unless the author later chooses it after seeing the exact price and terms.
